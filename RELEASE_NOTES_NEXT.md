# Release notes — next release (draft)

_Draft for the next release after 1.8.0. Keep adding to this as more changes land._

## ✨ General Improvements

- **New tool: Stamp** (⌘5). Add a small text overlay — "Example School Band", "Property of the Music Dept" — to your parts, like a rubber stamp. Set the text, font, size, colour, an optional box around it, and which of nine positions on the page it sits in, with a live preview as you go. Save as many named stamps as you like.
- The Stamp tab also stamps PDFs you already have: drop them in, choose every page or just the first page of each, pick an output folder, done. Originals are never overwritten.
- Stamps are burned into the page, so they print everywhere and can't be deleted out of the PDF.
