# Release notes — next release (draft)

_Draft for the next release after 1.8.0. Keep adding to this as more changes land._

## ✨ General Improvements

- **New: stamps.** Add a small text overlay — "Example School Band", "Property of the Music Dept" — to your parts, like a rubber stamp. Open the designer from **File ▸ Stamp…** (⌥⌘S): set the text, font, size, colour, an optional box around it, and which of nine positions on the page it sits in, with a live preview. Save as many named stamps as you like. Stamps are burned into the page, so they print everywhere and can't be deleted out of the PDF.
- You can stamp existing PDFs straight from the designer — drop them in, pick an output folder, done.
